# Python Digital Signature
This project is a Python implementation of a digital signature system using RSA and MD5 algorithms.

## Features:
- Digital signature generation using RSA and MD5
- Signature verification process

## Installation:
1. Clone this repository:
   ```bash
   git clone https://github.com/Naaa123-me/python-Digital-Signature.git
   
2. Install dependencies:
pip install -r requirements.txt

4. Run the application:
python main.py

6. Generate a digital signature:
python generate_signature.py
